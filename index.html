🧩 Mint Function Clarification

The smart contract contains a mint function that is strictly restricted by the onlyOwner modifier.

Ownership of the contract has been permanently renounced, which means there is no owner address capable of calling the mint function.

As a result, minting new tokens is technically impossible. The total supply is fixed and verifiable on-chain.This behavior is fully transparent and verifiable on-chain via BscScan.

Ownership Status: Renounced (irreversible)

🔐 Ownership Renounced

Ownership of the CM Token smart contract has been permanently renounced. This removes all privileged control and ensures that no owner-only functions can ever be executed again.

After ownership renouncement, no address has permission to call restricted functions such as minting. The token supply is therefore fixed and immutable.
